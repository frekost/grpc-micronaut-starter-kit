## Overview

The free v1 demonstrates the essential components of a Java gRPC microservice:

- **Java 21** — Modern Java development.
- **Micronaut 4** — Application framework and dependency injection.
- **gRPC** — Remote procedure calls between services.
- **Protocol Buffers** — Service contracts and message definitions.
- **Error handling** — Centralized gRPC error handling.
- **Automated tests** — Tests for application behavior.
- **Maven** — Dependency management, code generation, and build lifecycle.

It is a starting point for learning how these technologies work together in a runnable Java microservice project.

## Requirements

Make sure you have the following installed:

- JDK 21
- Apache Maven

Verify your environment:

```bash
java -version
mvn -version
```

## Quick Start

### 1. Get the Source Code

Clone the free v1 repository:

```bash
git clone https://github.com/frekost/grpc-micronaut-starter-kit.git
cd grpc-micronaut-starter-kit
```

### 2. Build and Verify

Run the following command from the project directory:

```bash
mvn clean compile verify
```

### 3. Run the Application

Start the application by running the following main class from your IDE:

```text
org.frekost.micro.Application
```

For detailed setup instructions, follow the **[Free v1 Quick Start Guide](https://frekost.github.io/grpc-micronaut-starter-kit/quick-start/)**.
